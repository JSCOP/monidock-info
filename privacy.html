개인정보처리방침

적용일: 2026년 10월 21일

이 문서는 MoniDock의 Google Calendar 연동이 데이터를 처리하는 방법을 설명합니다. 기본 캘린더와 양방향으로 동기화하는 새 버전 및 기존 단방향 버전의 차이를 함께 안내합니다.

1. 접근하는 데이터와 권한

새 버전은 https://www.googleapis.com/auth/calendar.events 권한을 요청합니다. 이 권한은 사용자가 접근할 수 있는 캘린더들의 일정을 조회·생성·변경·삭제할 수 있는 범위입니다. 권한 자체는 기본 캘린더에만 한정되지 않지만, 현재 MoniDock의 양방향 동기화 대상은 Google 계정의 기본 캘린더(‘내 일정’)입니다.

https://www.googleapis.com/auth/calendar.app.created 권한도 요청합니다. 이 권한은 앱이 만든 보조 캘린더와 그 일정을 관리하는 데 쓰이며, 새 버전에서는 이전 단방향 버전이 만든 ‘MoniDock 일정’ 캘린더를 정리하는 데 사용합니다. 기존 단방향 버전은 이 권한만 요청합니다.

2. 사용 목적

PC와 Google Calendar 사이에서 일정의 추가·수정·삭제를 양방향으로 반영하여 여러 기기에서 같은 일정을 사용할 수 있도록 합니다. 오늘을 기준으로 최근 30일부터 앞으로 365일까지의 기본 캘린더 일정을 조회하며, 일정 제목, 시작·종료 날짜와 시간, 종일 여부, 상태, 일정 식별자와 수정 시각을 처리합니다. PC에서 만든 시간 일정에는 사용자가 정한 알림 설정을 적용합니다.

기존 단방향 버전은 PC 일정의 내용과 날짜 등을 별도 ‘MoniDock 일정’ 캘린더로 보내며, Google에서 변경한 내용을 PC로 가져오지 않습니다.

3. 저장과 전송

PC의 일정은 날짜별 텍스트 파일로, Google의 일정은 사용자의 Google 계정에 저장됩니다. 새 버전에서는 Google에서 가져온 일정도 PC의 일정 파일에 기록됩니다. 별도의 MoniDock 중계 서버 없이 PC에서 Google API와 직접 통신합니다.

연결 유지에 사용하는 갱신 토큰은 Windows의 사용자별 암호화 기능(DPAPI)으로 보호하여 해당 PC에 저장합니다. 동기화 상태에는 일정 식별자, 수정 시각, 마지막으로 동기화한 일정 줄과 날짜 등이 저장됩니다. 일정 파일과 동기화 상태 파일에는 토큰과 같은 별도의 암호화를 적용하지 않습니다.

4. 공유와 제한적 사용

이 연동은 Google 사용자 데이터를 광고, 판매, 사용자 프로파일링 또는 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보는 명시된 일정 동기화 기능에만 사용하며 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

5. 연결 해제와 삭제

MoniDock의 ‘구글 캘린더 연결 해제’ 메뉴를 사용하거나 Google 계정의 연결된 앱 설정에서 접근 권한을 철회할 수 있습니다. 앱에서 연결을 해제하면 PC에 저장된 연결 토큰을 삭제하고 Google 토큰의 철회를 요청합니다.

연결을 해제해도 PC와 Google에 저장된 일정은 남습니다. 새 버전은 연결 해제 시 PC에 저장된 일정별 동기화 기록을 비웁니다. 양쪽의 데이터를 따로 삭제하려면 먼저 연결을 해제한 뒤 PC의 일정 파일과 Google의 해당 일정을 각각 삭제해 주세요. 연결된 상태에서 일정을 삭제하면 그 삭제가 다른 쪽에도 반영될 수 있습니다.

기존 단방향 연결에서 새 버전으로 전환할 때는 이전 ‘MoniDock 일정’ 캘린더를 삭제하고, 동기화 범위 안의 PC 일정을 기본 캘린더에 반영합니다. 이전 캘린더에서만 추가하거나 수정한 내용은 PC 파일에 없을 수 있으므로 전환 전에 별도로 보관해야 합니다.

6. 문의와 변경

문의는 Google 로그인 동의 화면에 표시되는 지원 이메일로 보내 주세요. 데이터 처리 방식이 바뀌면 이 문서를 갱신합니다.
